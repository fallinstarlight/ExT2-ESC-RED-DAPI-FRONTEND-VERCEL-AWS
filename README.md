# Eamen de Escalamiento de redes tema 2
## Doble API en EC2 + frotend + RDS DB

User => Vercel => APIArtists/APIAlbums => RDS

## Pasos
### TM 1 (DB OWNER)
Ejectuta *Dump20261018* en tu conexión activa de RDS (preferiblemente desde Workbench)
Usa CTRL + ENTER para ejecutar todo de una vez.
> La migración de la BD incluye estructura del esquema, procedimientos y todos los datos
Verifica que toda la información se haya copiado correctamente
> SELECT COUNT(track_id) FROM Tracks;
Debería arrojar 1045
> SELECT COUNT(album_id) FROM Albums;
Debería arrojar 85
> SELECT COUNT(artist_id) FROM Artists;
Debería arrojar 21
> SELECT ROUTINE_SCHEMA, ROUTINE_NAME, DEFINER, SECURITY_TYPE
> FROM information_schema.ROUTINES
> WHERE ROUTINE_TYPE = 'PROCEDURE'
> AND ROUTINE_SCHEMA = 'music_catalog';
Para comprobar que existen todos los procedimientos.

Recuerda permitir el tráfico en el puerto 3306 desde cualquier IP

### TM2 (Vercel User)
Sube el archivo *index.html* y las carpetas *css* y *js* a Vercel.
Verifica que la página se muestre correctamente.
No va a funcionar todavía porque no existen las APIs, pero el diseño general debería de ser visible.
NO subas las carpetas APIALbums, APIArtists ni db.

### TM3 (APIArtists)
Copia la carpeta APIAlbums a tu EC2 de windows server
Ejecuta en una terminal
> winget install PHP.PHP.8.4
> mkdir C:\EXT2\
> mkdir C:\EXT2\public
En el explorador de archivos, coloca la carpeta APIAlbums en la carpeta C:\EXT2
Los tres archivos PHP *router* *index* & *db* copialos en la carpeta public/
El archivo .env deberá permanecer en la carpeta EXT2.
Ve a C:\php y busca el archivo *php.ini*
Busca las líneas que dicen ;extension=pdo_mysql y ;extension=mbstring Elimina el ; y guarda el archivo.
Para arrancar el servidor, abre la terminal
> cd C:\EXT2\public
> PHP -S localhost:8000 router.php
No va a funcionar porque aún no tenemos la base de datos.
